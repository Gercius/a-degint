# A Degint?

Svetainė - https://gercius.github.io/a-degint/

**A Degint?** - internetinė programėlė skirta patikrinti a degint deginamus dalykus deginamoje vietoje.  
Ir ar **galimai** neuždūminsit kaimynų.

## Naudojimas
- Į paieškos laukelį įvedamas namo adresas
- Rodoma informacija ar **galimai** uždūminsit kaimynus

**Pastabos**
- Vėjo kryptis (mėlynos rodyklės) turėtų sufleruoti a degint ir neįvedus adreso
- Gali būti, kad nėra visų adresų, galite naudoti kaimyno/kaimynkos
- Rodoma informacija yra apytikslė, ypač **galimai** uždūminamų namų aptikimas (žymimas raudona spalva)

## Run Locally

```bash
npm install
npm run dev
```
