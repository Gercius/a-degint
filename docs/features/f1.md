# F1 — Village Map: Feature Plan

---

## Overview

Set up the React/Vite/TS project and render the pre-loaded village map that the rest of the app builds on: constrained to the village bounds, showing building footprints and address labels, and supporting later visual states like selected and downwind-highlighted buildings.

---

## Phase 1 — Project Scaffolding

**Goal:** Working dev environment with all dependencies installed.

- [x] **1.1** Scaffold project with Vite: `npm create vite@latest a-degint -- --template react-ts`
- [x] **1.2** Install core deps: `react-leaflet`, `leaflet`, `zod`, `sass`
- [x] **1.3** Install type stubs: `@types/leaflet`
- [x] **1.4** Add Leaflet CSS import to `main.tsx` (`leaflet/dist/leaflet.css`)
- [x] **1.5** Fix Leaflet default marker icon broken path (webpack/vite asset issue — patch `L.Icon.Default.mergeOptions`)
- [x] **1.6** Create base SCSS module structure: `styles/`, `components/`
- [x] **1.7** Verify dev server runs and blank page loads without console errors

---

## Phase 2 — GeoJSON Data Acquisition

**Goal:** Have a real `.geojson` file with village building footprints and address numbers ready to bundle.

- [x] **2.1** Identify village bounding box coordinates (lat/lon min/max)
- [x] **2.2** Write Overpass Turbo query to fetch buildings with `addr:housenumber` within the bounding box:
    
    ```
    [out:json][bbox:minLat,minLon,maxLat,maxLon];(  way["building"];  relation["building"];);out body geom;
    ```
    
- [x] **2.3** Export result as GeoJSON from Overpass Turbo → save as `src/data/village-buildings.geojson`
- [x] **2.4** Manually verify the file: open in [geojson.io](https://geojson.io/), confirm buildings look correct
- [x] **2.5** If address numbers are sparse, cross-check with OSM and note gaps (no fix needed, just awareness)
- [x] **2.6** Commit the `.geojson` file to the repo as a static asset

---

## Phase 3 — Map Component (Base)

**Goal:** Render the base Leaflet map centered on the village and ready to host overlay components.

- [x] **3.1** Create `src/components/village-map/village-map.tsx` and `village-map.module.scss`
- [x] **3.2** Render `<MapContainer>` with hardcoded `center` (village lat/lon) and `zoom`
- [x] **3.3** Add `<TileLayer>` with OSM tile URL and proper attribution string
- [x] **3.4** Set map container to fill viewport (`height: 100vh`, `width: 100%`) via SCSS module
- [x] **3.5** Confirm map tiles load and you can pan/zoom manually

---

## Phase 4 — Map Constraints

**Goal:** Prevent panning outside the village area and enforce zoom limits.

- [x] **4.1** Define a `VILLAGE_BOUNDS` constant (`LatLngBoundsExpression`) from the bounding box in Phase 2
- [x] **4.2** Set `maxBounds` on `<MapContainer>` to `VILLAGE_BOUNDS`
- [x] **4.3** Set `maxBoundsViscosity={1.0}` to hard-block panning outside bounds
- [x] **4.4** Determine `minZoom` value experimentally: the zoom level where the whole village fits in viewport
- [x] **4.5** Set `minZoom` and `maxZoom` on `<MapContainer>` (e.g. `minZoom=15`, `maxZoom=19`)
- [x] **4.6** Set initial `zoom` to the `minZoom` value so village loads fully visible
- [x] **4.7** Manually test: try to pan away — map should snap back; try to zoom out past min — should be blocked

---

## Phase 5 — Building Footprints Layer

**Goal:** Render all building polygons from the GeoJSON onto the map, with styling that can support later feature states.

- [x] **5.1** Import `village-buildings.geojson` directly in the component (Vite supports JSON imports natively)
- [x] **5.2** Add `<GeoJSON>` layer from `react-leaflet` passing the imported data as `data` prop
- [x] **5.3** Define building styles for neutral buildings plus later map states (`selected` in green, `downwind` in red)
- [x] **5.4** Pass `style={buildingStyle}` to `<GeoJSON>` so building appearance reacts to selection/downwind state
- [x] **5.5** Verify all building footprints appear in correct positions and update visually when later features pass selected/downwind buildings into the map

---

## Phase 6 — Address Number Labels

**Goal:** Show house number labels on buildings that have `addr:housenumber` in their GeoJSON properties.

- [x] **6.1** Create a helper `getBuildingCenter(feature, layer)` that returns the polygon's centroid using `layer.getBounds().getCenter()`
- [x] **6.2** Add `onEachFeature` prop to `<GeoJSON>` — for each feature with `properties.addr:housenumber`, bind a `L.tooltip` (permanent, no interaction) at the centroid
- [x] **6.3** Style tooltips via Leaflet CSS overrides in SCSS: small font, no border/shadow, semi-transparent background
- [x] **6.4** Test at various zoom levels — ensure labels don't visually clutter at min zoom
- [x] **6.5** Add a zoom listener that hides labels below a threshold zoom level (`HOUSE_NUMBER_MIN_ZOOM = 16`)

---

---

## Definition of Done

- Village map loads centered on the village, no surrounding areas visible
- Building footprints render from bundled GeoJSON and can switch between neutral, selected, and downwind-highlighted states
- Address numbers appear as permanent tooltip labels where data exists and hide automatically below the label zoom threshold
- Cannot pan or zoom out beyond village bounds
- No hardcoded magic values — everything in `map.ts`
- Map is ready to host later overlays and interactions used by F2/F3
- Zero console errors in dev build
